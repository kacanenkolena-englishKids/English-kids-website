# Английский с удовольствием

Образовательный сайт на русском языке для детей 5–11 лет. HTML, CSS и JavaScript, без сборки, обязательного сервера, регистрации, платных API и внешних библиотек.

## Готово на первом этапе

- Адаптивная главная страница с оригинальной совой, нарисованной CSS, и навигацией.
- Урок Present Simple: объяснения и примеры с переводом, выбор ответа, сборка предложения, сопоставление слов, мини-тест с объяснениями.
- Три оригинальные истории по 22 предложения. У каждой — переводы по нажатию, словарь из 10 слов, 5 вопросов и 5 заданий True/False.
- Выделение изучаемой грамматики и браузерная озвучка текущей части.
- Возрастной режим: по 6 предложений (последняя часть — 4) для детей 5–7 лет или весь текст для 8–11 лет.
- Локальный прогресс: баллы, выполненные задания, открытые переводы, выбранный раздел и возрастной режим. Повторное выполнение не даёт дополнительные баллы. Есть сброс с подтверждением.
- Информационная страница для родителей и демонстрационная кнопка связи.

## Следующий этап: Pre-A1 и Beginner A1

Дизайн, цвета, исходные тексты Present Simple и его ключи прогресса сохранены. Дополнительный курс находится в `course-data.js` (материалы) и `course.js` (интерактивность). В каталоге показаны только готовые уроки.

- **Pre-A1, 7 тем:** алфавит (все 26 букв с озвучкой), числа 1–20, цвета, животные, семья, игрушки, приветствия.
- **Beginner A1, 5 тем:** личные местоимения; to be (am/is/are, отрицания и вопросы); a/an; множественное число; have got/has got (утверждения, отрицания и вопросы).
- **В каждом новом уроке:** объяснения на русском, 3 примера с переводом и озвучкой, словарь из 8–12 слов, 3 задания на выбор, сборка предложения, сопоставление 4 пар, мини-тест из 5 вопросов с объяснениями ошибок.
- **24 оригинальные истории:** по 2 в каждом новом уроке, по 20 предложений с индивидуальными переводами. У каждой истории собственный словарь из 10 слов, 5 вопросов и 5 True/False; ошибки сопровождаются цитатой-подсказкой из текста.
- **Чтение:** перевод предложения нажатием, выделение слов темы в Pre-A1 и грамматики в Beginner A1, озвучка видимого текста и остановка. В новых историях режим 5–7 лет показывает по 5 предложений; режим 8–11 лет — все 20. Исходный Present Simple сохраняет прежнее деление по 6 предложений.
- **Игры:** «Угадай животное» (6 загадок), «Найди слово» (2 поля по 4 слова), «Собери предложение» (5 предложений). За один и тот же ответ повторно баллы не начисляются.
- **Проверка знаний:** 14 вопросов по Pre-A1 или 10 по Beginner A1. Это учебная самопроверка, не официальный экзамен CEFR. Мини-тест Present Simple также доступен.
- **Для родителей:** порядок прохождения курса, рекомендации по возрасту, счётчики пройденных новых мини-тестов и прочитанных историй, демонстрационная связь и общий сброс с подтверждением.
- Ответы на новые задания, выбранные разделы, страницы чтения, переводы, отметки о прочтении и прохождении мини-тестов сохраняются локально. Исходный прогресс Present Simple продолжает храниться в прежнем ключе. Страница родителей сбрасывает оба набора данных.

Остальные темы Elementary A1 и A2 не добавлены: разработка остановлена для подтверждения этого этапа. Для детей, начинающих с нуля, особенно 5–7 лет, чтение предполагает помощь взрослого. Знакомство со словами не равно самостоятельному освоению всей грамматики текста.

## Как открыть

Самый простой способ: скачайте файлы проекта в одну папку и откройте `index.html` двойным щелчком. Сборка и установка пакетов не нужны. Для надёжного сохранения прогресса рекомендуем локальный сервер: поведение localStorage при открытии через file:// зависит от браузера.

Если установлен Python, откройте терминал в папке проекта и выполните:

```sh
python3 -m http.server 8000
```

Затем в браузере на том же компьютере введите `http://localhost:8000`. Для остановки нажмите Ctrl+C в терминале. В Windows можно использовать `py -m http.server 8000`.

В облачном Codex localhost относится к облачной машине, а не вашему компьютеру. Чтобы открыть сайт у себя, скачайте файлы проекта. Никакая публикация автоматически не выполняется.

## Озвучка и данные

Нажмите «Слушать текст» в разделе историй. Нужен браузер с Web Speech API и доступным английским голосом. При необходимости установите английский голос в настройках устройства. Некоторые системные голоса требуют интернет. Если голоса недоступны, текст и все задания продолжают работать.

Ответы и прогресс не отправляются на сервер. Прогресс хранится в localStorage текущего браузера и не синхронизируется между устройствами. При запрете хранилища сайт работает в пределах сеанса. Не вводите персональные данные: форм их сбора нет.

## Публикация на GitHub Pages — только по решению владельца

1. Сохраните `index.html`, `style.css`, `app.js`, `stories.js`, `course-data.js` и `course.js` в корне ветки `main` вашего репозитория GitHub.
2. Откройте **Settings → Pages → Build and deployment**.
3. Выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
4. После успешного развёртывания GitHub покажет адрес сайта в разделе Pages.

Все пути относительные; сайт подходит для подпапки репозитория на GitHub Pages. Секреты, сборка и платные сервисы не нужны. Публикация в рамках этого задания не выполнялась.


## Проверка разработки

Сам сайт не требует установки пакетов. Необязательный браузерный тест `tests/course.cjs` использует Playwright и Chromium в среде разработчика. Запустите локальный сервер из корня проекта, затем:

```sh
node tests/course.cjs
node tests/course-edge.cjs
```

Если Playwright доступен не как локальный пакет, задайте путь к модулю через `PLAYWRIGHT_MODULE`. Дополнительно поддерживаются `SITE_URL` и `CHROMIUM_PATH`. По умолчанию тест открывает `http://127.0.0.1:8000` и `/usr/bin/chromium`.

Проверяются все 12 новых уроков, все 24 истории, полнота текстов и словарей, выбор ответа, неверные и пустые ответы, сборка предложений, сопоставление, обе проверки знаний, все игровые задания, сохранение прогресса, отсутствие повторных баллов и общий сброс. Проверяются размеры экрана 360, 390, 768 и 1440 пикселей. В тесте озвучки проверяются текст и язык, переданные браузеру; реальное звучание нужно проверить на устройстве с английским голосом.

Для ручной проверки откройте «Уроки», выберите тему, пройдите вкладки «Разбираемся», «Тренируемся», «Читаем истории», «Мини-тест». Попробуйте неправильный ответ, откройте перевод, переключите возрастной режим и перезагрузите страницу. В «Для родителей» проверьте отметки выполнения.

В управляемом Chromium облачной среды переходы `file://` запрещены политикой администратора: этот необязательный тест отмечается как пропущенный, без обхода политики. Проверка сайта через локальный HTTP-сервер выполнена. На личном компьютере можно открыть `index.html` напрямую; для предсказуемого сохранения данных рекомендуется локальный сервер.
